# Добро пожаловать в CDN

После добавления картинки в [/static](./static) выполни
```bash
bun gen
```
это создаст ts файл, в котором сгенерируется объект с перечислением всех картинок в объекте и мета инфой, в том числе для TS типизации


## Предобработка изображений перед загрузкой:
- Все картинки подгоняются под размер и качеству сервисом [🧃 Squoosh](https://squoosh.app/)
- Также стоит прогнать через сжатие используя [🗜️ Compressor](https://compressor.io/)


## Загрузка картинок в CDN через Github Actions
- Автоматически загрузятся вместе с деплоем бэкенда [Backend - TS Server](https://github.com/hmkteam/gamedev/actions/workflows/backend.ym)
- Или отдельно загрузить **только** картинки запустив [📸 CDN Image Sync](https://github.com/hmkteam/gamedev/actions/workflows/cdn.yml)



# Про CDN домены

## https://static.hamsterkombatgame.io
Тут хранятся файлы из директории [/static/*](./static). Это картинки небольшого размера, которые не жалко хранить в git. С помощью Github Actions можно самостоятельно деплоить новые файлы

## https://cdn.hamsterkombatgame.io
Здесь файлы, которые не хранятся в git, например, аватарки пользователей, динамически подгружаемые из Telegram, или огромные гигабайтные файлы. Сюда можно загрузить только через друзей админа
